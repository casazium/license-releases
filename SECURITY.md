# Security

This repository holds no source code (see `README.md`) — it only
mirrors public download artifacts for the Casazium License Server,
whose actual source lives in the private `casazium/license` repo.

If you've found a security vulnerability in the License Server,
casazium.com, or docs.casazium.com, please don't open an issue here.
Report it privately: see
[docs.casazium.com/docs/license-server/security](https://docs.casazium.com/docs/license-server/security)
for how to report and what to expect, or email **bob@casazium.com**
directly.
